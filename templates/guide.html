Guide

{{ cfg_title }} keeps text, links and files under an address of three words, such as apple-banana-cherry. Share the words, the full address or its QR code, and choose how private the paste is and how long it lasts.

Create a paste

Write or paste your text, choose a privacy level and an expiry under Options (they open by themselves once the box holds text), add files under Attach files if you want (or drop or paste them onto the form), then select Create paste. You are taken to the new paste, whose three words are its address.

A paste can be text, files or both. Files can add up to {{ max_file_mb }} MB per paste{% if self.offers("secret") %}, and each file of a secret paste can be at most {{ max_secret_file_mb }} MB{% endif %}.

{%- if self.offers("public") || self.offers("unlisted") %}

When a public or unlisted paste is a single web address and nothing else, it becomes a short link: opening the paste takes you straight to that address.

{%- endif %} {%- if uploader_password %}

This server asks for an uploader password before it accepts a new paste. Ask its administrator for it.

{%- endif %}

Open a paste

Open the address in your browser, or type the three words into the box on the start page. Pasting the paste's link into the box opens it as well. Spaces, hyphens and capital letters do not matter, so "Apple Banana Cherry" and "applebananacherry" work too; words typed without anything between them only need a space or hyphen when they could be read two ways. Four letters per word are enough when the words are separated. Press Enter to open the paste. While you type, the words that fit appear under the box; Tab takes the first one.

The same box keeps text, so it says under itself what pressing the button will do: open the paste the words name, or keep what you typed as a new paste when no paste has those words. To keep the words of an existing paste as text, choose Keep as a new paste.

Privacy levels

{%- if self.offers("public") %}

Public

Anyone with the address can see the paste{% if editable %}, change it if editing is allowed{% endif %} and delete it.{% if listing %} Public pastes also appear in the list of public pastes.{% endif %}

{%- endif %} {%- if self.offers("unlisted") %}

Unlisted

The paste is never listed, so only people who know its address can find it. They can see{% if editable %}, change{% endif %} and delete it.

{%- endif %} {%- if self.offers("readonly") %}

Read-only

Anyone with the address can see the paste, and nobody can change or delete it; it goes when it expires. It is not encrypted and has no password. Only the administrator can remove it.

{%- endif %} {%- if self.offers("private") %}

Private

The text and every file are encrypted on the server, with a key that only the password unlocks. Opening the paste needs the password, and the opened page can {% if editable %}change and {% endif %}delete it without asking again. File names are not shown until the paste is open.

After you open a private paste, its download links work for ten minutes. Open it again for new links.

{%- endif %} {%- if self.offers("secret") %}

Secret

Your browser encrypts the text, the file names and the files before anything is sent, and the password never leaves your device. Opening and deleting happen in your browser as well, so secret pastes need JavaScript, and they cannot be changed. Once opened, the page can delete the paste.

Before you open it, the page shows the ciphertext as stored. Decrypt it elsewhere lists what another tool needs beside the password: the key is the first 32 of 64 bytes from PBKDF2-HMAC-SHA256 over the password with the salt and iteration count shown, and AES-256-GCM takes the IV, the associated data and the tag. The result is JSON with the text and the file names. A paste that burns after reads shows its ciphertext only once you ask to open it, and text beyond about 64 KiB is not shown this way.

{%- endif %} {%- if self.offers("private") || self.offers("secret") %}

Password

Private and secret pastes are encrypted under a password. Nobody can recover a forgotten one, not even the administrator.

{%- endif %}

Expiry

Every paste is deleted when its expiry time has passed.{% if let Some(max) = max_expiry %} The longest expiry here is {{ max }}.{% endif %} Longer expiries are only there if the administrator turned them on.

Burn after reads

Burn after reads deletes a paste once it has been read that many times; 0 turns it off. Viewing the paste, opening it for editing, fetching its raw text and reading it through the API each count as a read, and so does the preview a chat app fetches when you send it the address. Downloading files does not. After the last read, the page that showed it keeps its file downloads working for ten minutes.

Syntax highlighting

{%- if highlight %}

Automatic detects the language from the first line. Or choose a language under Syntax to colour code by its structure. The server does the highlighting, so it works without JavaScript. Very large pastes are shown without colours.

{%- else %}

Syntax highlighting is turned off on this server, so code is shown as plain text.

{%- endif %}

Files

Files can be added to any paste and downloaded one by one or as a zip. Interrupted downloads of single files resume, except in private pastes; zip downloads do not.

Share

Each of the three words has a copy button, and Copy link copies the full address. Copy text copies the paste's text, and Share opens your device's share sheet where there is one.{% if qr %} The QR code button shows the address for a phone camera.{% endif %} Raw text opens the paste as plain text. Add ?view to a link's address to see where it goes before following it.

{%- if editable %}

Change a paste

Allow editing is pre-checked on this server. Untick it to keep a paste fixed. A private paste is changed from its opened page. Read-only and secret pastes cannot be changed.

{%- endif %}

Delete a paste

Delete takes effect at once and cannot be undone. Private and secret pastes are deleted from their opened page, so whoever has the password can delete them. A read-only paste cannot be deleted; it goes when it expires.

{%- if admin %}

Administrator

The administrator can sign in to see every paste's address and details and to delete any paste. The administrator cannot read private or secret pastes.

{%- endif %}

API

Everything here also works through the REST API at /api/v1, which needs no key. The API page describes every call, each with a curl command for this server.
